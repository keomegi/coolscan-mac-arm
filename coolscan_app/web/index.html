Saved settings

Keep the settings you use for one kind of work under a name, and switch between them here. Saving under a name that exists replaces it. A saved set holds how you scan and save: film type, resolution, dust removal, grain, focus and exposure choices, colour space, file name choices. It does not hold the folder, the roll, or who to tell. "Not saved" means the settings in use differ from every saved set.

Film

Colour of negatives

"Each frame on its own" works out the colour of a negative from that one frame, which goes wrong when the frame is mostly one colour (grass, a sunset, a blue sky). A film profile takes the colour from the film instead: the app measures every frame you scan, and "Save this roll's film…" turns the measurements of the roll you are in into a profile under the film's name. Pick it for later strips and rolls of the same film and every frame gets the same colour. Brightness is still set for each frame. Thumbnails always use "each frame on its own".

Roll

Scans go into one folder per roll, and every strip of the roll adds to it with continuing numbers. The list holds every roll in the target folder: pick one to carry on in it. The description is saved as Description.txt in the roll's folder whenever you change it. Changing the roll number renames the folder and the R… part of its files; nothing is deleted.

Scan quality

Dust removal finds dust and scratches in the infrared picture. Built in leaves clean film exactly as scanned, gives light dirt its light back and fills heavy dirt from the film around it. Driver is the older method, which changes more of the picture; in Archive mode it needs a second pass. Multi-sample gives cleaner shadows and takes that many times longer on this scanner. Multi-Exposure scans each frame a second time with a longer exposure and reads the dense parts of the film from that pass: the shadows of a slide, the highlights of a negative. It helps slides most; on negatives the gain is small. Each frame takes at least twice as long. Grain reduction and colour restoration are the app's own stand-ins for Nikon's GEM and ROC, and are off unless you choose a level.

Save as

Archive mode saves two folders from one pass: RAW (the untouched scan with the infrared as a 4th channel) and Positive (the finished picture, dust removed if ticked). With "Scan only the cropped part" a cropped frame is scanned as just that part, which is quicker because less film is stepped over and less data crosses the scanner's slow USB link; unticked, the whole frame is scanned and the crop is cut out when the file is saved. Archive mode always scans the whole frame so its RAW file keeps it. The infrared picture is an extra file ending in _IR.tif that shows only the dust and scratches; dust removal works the same with it unticked. All files are 16-bit TIFF.

File names

Names are built as prefix, scan date, picture number, then the number of the roll you are scanning, which is always there. The next number counts on by itself from the pictures already in the roll; type another number to carry on from there once. A name that is taken is skipped, never overwritten. "Photo taken" sets the date galleries sort by: with only a year the files get today's day and time in that year.

Focus & exposure
Do once, now

Settings, used for every preview and scan

The buttons act once, right away, on the frame you are looking at. Calibrate focuses and measures the exposure, then switches the two settings below to keep both for every frame; Reset undoes that. "Pick" lets you click the big picture to choose where the scanner focuses.

When the scanner focuses. Never during the thumbnail pass. With Autofocus each frame once (the default) it focuses each frame the first time that frame is previewed or scanned, and every later pass of that frame (the scan, multi-sample, Multi-Exposure) reuses that lens position. Frames are focused again after a new strip, Eject, Reset, or a new focus point. Same focus for all frames uses the last Autofocus or Calibrate for every frame. Autofocus on every pass focuses before each pass. Manual never focuses. The Autofocus button focuses only the frame you are looking at; Calibrate also switches to the same focus for all frames. A cropped scan is focused on the whole frame (at the focus point, or its centre), then only the crop is scanned. The Activity list says each time the scanner really focuses.

Thumbnail & preview

The thumbnail is one quick pass over the strip that finds the frames; each frame's piece of it is what you see first. A preview is a quick scan of a frame that looks sharper. Neither is saved. Once a frame is scanned, the picture you see is the scan itself.

When a strip is done
Tell me

If a frame fails (for example autofocus), the rest of the strip is still scanned unless you tick "Stop at the first frame that fails". The scan log is ScanLog.txt in the roll folder. "Run a shortcut" runs one of your own shortcuts from the Shortcuts app and hands it the message as text, so the shortcut decides how it reaches you. ntfy is a free phone app that needs no shortcut.
