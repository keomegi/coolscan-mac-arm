When a strip is done

Tells you when a batch finishes or stops on an error. "Run a shortcut" runs one of your own shortcuts from the Shortcuts app and hands it the message as text, so the shortcut decides how it reaches you (an email to yourself, a reminder with an alert, a push app). ntfy is a free phone app that needs no shortcut.

Archive mode saves two folders from one pass: RAW (untouched scan with infrared as a 4th channel) and Positive (finished picture, dust removed if ticked).
