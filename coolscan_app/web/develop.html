Archive mode keeps the untouched scan with its infrared in each roll's RAW folder.

How to develop

Kodachrome: its cyan dye blocks infrared much as dust does, so dust removal can paint over parts of the picture. Check the result closely, or untick it.

Used for the picture on the right and for every file you develop. Nothing is scanned again. nkscan's dust removal (the older method) is not offered here: it works by scanning the film a second time.

Save

Each run saves into a new folder, Re-developed/<date and time> inside the roll's folder, with the same file names as the RAW files and a Develop log.txt. Nothing is ever overwritten.
